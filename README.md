# Build Requirements
1. make
2. i686-elf-gcc (Maybe pcc in the future)
3. nasm
# Minimum System Requirements
1. CPU: 486
2. Memory: 2 MB
3. Video: EGA (Text Mode)
4. Storage Controller: Floppy Drive Controller
5. Bus: ISA
# Recommended System Requirements
1. CPU: Pentium OverDrive
2. Memory: 8 MB
3. Video: Any supported 2D accelerator
4. Storage Controller: ATA
5. Bus: PCI
# Supported 2D Accelerators
1. 3Dfx Interactive Voodoo Banshee
